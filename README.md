# Projeto Farfalla

Site institucional desenvolvido para a Farfalla, com foco em apresentar visualmente a marca, seus serviços e suas informações de forma organizada, moderna e intuitiva.

## Sobre o projeto

O Projeto Farfalla consiste no desenvolvimento de um site institucional, buscando proporcionar uma experiência visual agradável, com uma identidade visual alinhada à proposta da marca.

O site foi desenvolvido para apresentar informações de maneira clara e facilitar a navegação dos visitantes.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades e características

- Layout organizado e intuitivo.
- Interface visual personalizada.
- Navegação entre as seções do site.
- Design responsivo para diferentes tamanhos de tela.
- Apresentação institucional da marca e de seus serviços.
